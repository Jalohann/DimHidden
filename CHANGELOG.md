# Changelog

## 1.2.0

- Adds a Dimming Strength submenu with Light, Medium, and Strong presets that apply immediately. Custom opacity values remain unchanged until a preset is selected.

## 1.1.1

- Fixes the look in Light Mode. Veils now take the color of the Dock's glass over your wallpaper instead of a fixed light gray, which showed as pale squares and gray circles on dark wallpapers.
- Fixes an undimmed sliver next to two-digit badges.

## 1.1.0

- Adds Report a Problem and Request a Feature to the menu, and shows the version.
- Logs errors to `~/Library/Logs/DimHidden/errors.log` so they can be reported.

## 1.0

- First release.
